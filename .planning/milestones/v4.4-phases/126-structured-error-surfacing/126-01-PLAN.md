<objective>
Close ERR-02: runner action-execution failures carry a structured `errorCode` an agent can branch on, and the op layer stops dropping errorCodes it already receives.

Purpose: Today `GameRunner.performAction` returns `{success:false, error}` with NO errorCode on two paths (continueFlow throw, flowState.actionError), and `stateless-ops.ts`'s `errorResult()` has no errorCode field/param at all — so `handleAction`/`handleSelectionStep`/`handleResolveChoices` silently drop the errorCode the underlying result already computed. Agents get message strings they cannot switch on.

Output: Extended `ErrorCode` enum, errorCode on the two runner gap branches, `OpResult.errorCode` field, and `errorCode` threaded through the wrapping op handlers.
</objective>
