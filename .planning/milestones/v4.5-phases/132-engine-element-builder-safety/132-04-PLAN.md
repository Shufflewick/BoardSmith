<objective>
Implement ENG-06 (F13): `executeForEach` snapshots its collection once on first frame entry (a stable identity list stored in `frame.data`) instead of re-evaluating `config.collection(context)` every iteration against a persisted index. A loop body that mutates the source collection no longer skips items.

Purpose: Re-fetching a live collection each iteration while advancing an iteration-count index is the classic mutate-array-by-index skip bug. The fix mirrors `executeEachPlayer`'s existing `eligibleSeats` snapshot pattern in the same file, storing JSON-plain identity (element `id` or primitive value) so the snapshot survives checkpoint restore mid-loop.
Output: A snapshot-on-first-entry `executeForEach` plus a red-first regression test with a mutating body.
</objective>
