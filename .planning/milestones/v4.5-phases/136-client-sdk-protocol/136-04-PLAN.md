<objective>
Unify the `MeepleClient` error contract and finish its connection/identity surface: (SDK-03) route all 18 public HTTP methods through ONE shared private response helper that checks `response.ok` before parsing (no more SyntaxError on non-JSON error bodies) and throws with the server `error` plus an optional `errorCode` on `!data.success` — migrating the 12 raw-JSON methods AND unifying the 6 existing ad-hoc throwers; (SDK-01) make `connect()` expose the awaitable open now that GameConnection has `opened`, and thread `connectImmediately`; (SDK-06) add `playerId` handling so the constructor skips `generatePlayerId()` when a playerId is provided and the error message names a field that exists.

Purpose: the split contract (12 methods return raw JSON, 6 throw, none carry errorCode) is already unworkable for first-party code (GameShell.vue re-invents a `.success` check inside a try/catch it doesn't need). One shared helper is the Pit-of-Success chokepoint. Per No Backward Compatibility this is a clean break — GameShell.vue migrates in Plan 05.
Output: one consistent throwing contract, an awaitable connect(), correct playerId handling, and a new fetch-mocked test sweep.
</objective>
