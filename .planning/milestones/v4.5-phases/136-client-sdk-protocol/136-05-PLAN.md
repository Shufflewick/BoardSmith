Migrate the in-repo consumers to the new SDK contracts: (SDK-01) delete the `setTimeout(100)` hack in `vue.ts` and clear `isSettingUp` from `GameConnection.opened`; (SDK-02) thread `connectImmediately: autoConnect` into `client.connect()` so `useGame({autoConnect:false})` never opens a socket to immediately kill it; (SDK-03) migrate every `GameShell.vue` lobby call site from the defensive `if (result.success)`-inside-try/catch pattern to try/catch-only, since those MeepleClient methods now throw. Per No Backward Compatibility, these migrate THIS phase (not deferred to Phase 138, which is games/MERC only).
Output: hack-free useGame, try/catch-only GameShell lobby handlers, corrected docs, and a new vue.test.ts.
</objective>
