Registry seeding — `game.ts:631-634`:
```
this._ctx._builtinSeededNames = new Set<string>();
for (const cls of BUILTIN_ELEMENT_CLASSES) {
  this._ctx.classRegistry.set(cls.name, cls);
  this._ctx._builtinSeededNames.add(cls.name);
}
```
`_builtinSeededNames` marks a name as a BUILT-IN default seed: overriding a builtin-seeded name with a
game class is legitimate (not a collision) — that override deletes the name from `_builtinSeededNames`.

Three write sites that today silently `Map.set`:
- `game.ts:783-786 registerElements` — unconditional `classRegistry.set(cls.name, cls)` +
  `_builtinSeededNames?.delete(cls.name)`.
- `game.ts:800-807 createElement` — sets only `if (!has(name) || _builtinSeededNames.has(name))`.
- `game-element.ts:362-366 create` — identical guard to createElement.

`isDevMode()` is already imported/used in `piece.ts` (WR-03) — same helper is the dev gate. A minified
build collapses names; `import.meta.env.DEV` false OR a mangled/single-char-name heuristic must suppress
the throw (Claude's discretion on the exact heuristic per CONTEXT).

<decisions>
## Locked decisions implemented here (D25)

- **Throw on different-constructor-same-name**, naming the colliding class and instructing the designer
  to rename it. NEVER silently overwrite. A collision is: the name is already registered to a DIFFERENT
  constructor that is NOT a built-in default seed (`_builtinSeededNames` membership means "override is
  fine, not a collision").
- **Idempotent same-constructor re-registration must NOT throw** — check identity: if the already-mapped
  value `=== cls`, it is a no-op, return quietly.
- **Dev-mode-gated** — only throw when `isDevMode()` (and/or the name is not a minified/single-char
  mangled name). A minified prod bundle that legitimately collapses names must not false-throw. Claude's
  discretion on the exact heuristic, provided: a real collision throws in dev AND a minified bundle does
  not throw.
- **One shared guard, three call sites** — extract a private `registerClass(name, cls)` (or similar) on
  the registry-owning surface that all three sites call, so a future write site cannot reintroduce the
  silent clobber. This is the pit-of-success mechanic (the easy path is the guarded path).
- Error message names the class + says to rename; NO paths/line-numbers/stack traces.
</decisions>
