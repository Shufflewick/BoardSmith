<objective>
Close SPACE-05 (D26): `availableActions` and `actionMetadata` can diverge and strand the board.

Root cause (proven in source, not the CONTEXT's assumed locus): in `buildPlayerState`
(`src/session/utils.ts`), `state.availableActions` is set from the RAW flow list
`availableActionsForSeat(flowState, playerPosition)` (`utils.ts:453`), but `state.actionMetadata` is
built by `buildActionMetadata(...)` (`utils.ts:530`) which DROPS any action whose `condition` is now
false (`action-metadata.ts:49-54`). So `availableActions` can be a STRICT SUPERSET of `actionMetadata`.
The client offers such an action, calls `start()`, looks up its (missing) metadata, and throws
`No metadata for action` (`useActionController.ts:1335`) — stranding the panel with a thrown error.

(`game.ts:1055-1064 getActionSpace` already derives its actions FROM `buildActionMetadata` and is
therefore consistent — it is NOT the divergence site. The broadcast path `buildPlayerState` is.)

Purpose: make `availableActions` and `actionMetadata` the SAME condition-checked set at their single
source (D26 single-source-of-truth), and add defense-in-depth so a transient divergence can never throw
and strand the board.

Output: `buildPlayerState` derives `availableActions` from the condition-checked metadata; the UI
no-metadata path becomes a logged no-op/resync; net-new regression proves both.
</objective>

<decisions>
## Locked decisions implemented here (D26)

- **Single source of truth (Claude's-discretion approach chosen):** in `buildPlayerState`, build the
  condition-checked metadata for the seat and derive `state.availableActions` from `Object.keys(metadata)`
  so the two CANNOT diverge — an action whose condition is now false is dropped from BOTH. Spectators
  (position 0) and the no-metadata-requested path keep the raw list (they get no metadata anyway and
  cannot strand a panel); the reconciliation applies wherever `actionMetadata` is emitted.
- **A now-false-condition action is genuinely unavailable** — dropping it from `availableActions` is
  correct, not papering over. Do NOT merely silence the UI throw and leave the divergence.
- **Defense-in-depth:** downgrade `useActionController.ts:1335` from a hard `No metadata` error to a
  logged no-op / resync (`devWarn` + return without stranding — the board stays interactive and re-syncs
  on the next state broadcast). Even a transient divergence can then never strand the board.
- No paths/line-numbers/stack traces in any surfaced message.
</decisions>
