<objective>
Deliver VIS-02: a `diffPlayerViews` utility that tells a developer exactly which elements/fields
two seats see differently, so hidden info can be verified as hidden.

The engine deliberately anonymizes IDs for zone-hidden children (fresh synthetic negative IDs per
serialization call) while KEEPING stable IDs for individually-hidden elements (FLIP correlation).
Raw id-based diffing therefore produces false noise. Per RESEARCH Open Question 1, this plan scopes
the diff around per-element visibility (VIS-01's isElementVisible): elements visible-to-exactly-one-
seat become onlyInA/onlyInB, and only elements BOTH seats can see are compared for attributeDiffs.
This sidesteps the anonymized-id correlation problem entirely.

Purpose: Verify hidden information stays hidden by comparing two seats' views structurally.
Output: `src/testing/view-diff.ts` (new) + colocated test + barrel export.
</objective>
