<objective>
Deliver VIS-03: a headless DOM-leak test utility that renders the game UI as seat N and fails when
a hidden element's identity (rank/suit/face-image, or any custom attribute) leaks into the rendered
markup.

This is Highest-Risk-Item #2 for v4.4: the matcher itself must have NO blind spots. It therefore
derives forbidden markers from the FULL, unfiltered `toJSON()` attributes of every element NOT
visible to the target seat (NOT a hardcoded rank/suit list) — so it catches any attribute the
engine's redaction allowlist might miss for a game's custom attribute names. A leak-detector with no
failing case is unproven, so the test MUST include a positive control (a deliberately-injected leak
that the matcher catches).

Purpose: First DOM-level hidden-info regression guard in the framework.
Output: `src/testing/dom-leak.ts` (new) + jsdom test with positive control + barrel export.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| seat-filtered gameView → rendered DOM | The rendered markup is the actual production leak surface; the matcher guards it |
| matcher configuration (allowlist) → pass/fail verdict | An over-broad allowlist can silently convert a real leak into a false PASS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-124-05 | Information Disclosure | assertNoHiddenInfoLeak false-negative | mitigate | Derive forbidden markers from FULL unfiltered `el.toJSON()` of every `!isVisibleTo(seat)` element (never a hardcoded identity-field list), so unknown/custom attributes are covered. A mandatory positive-control test proves the matcher fails on an injected leak — a detector with no failing case is rejected at review. |
| T-124-06 | Information Disclosure | over-broad allowlist masks a real leak | mitigate | Allowlist is a narrow caller-supplied predicate scoped to specific markers/attributes; the allowlist test proves a real leak still fails when a legitimate overlapping value is exempted. Scan is scoped to data-* + img[src]/background-image, not blind text search. |
| T-124-07 | Tampering | mounting AutoUI standalone (A1) | mitigate | If AutoUI throws without a provider, wrap with a minimal no-op provideBoardInteraction stub only — no GameShell/WS/session mocking that could alter the real rendering/leak surface. |
| T-124-SC | Tampering | package installs | n/a | No packages installed this phase (@vue/test-utils, jsdom, vitest all pre-existing); no supply-chain checkpoint required. |
