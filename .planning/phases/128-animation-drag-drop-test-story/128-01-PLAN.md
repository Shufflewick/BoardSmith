| Boundary | Description |
|----------|-------------|
| test harness → composable runtime | Test mode is an in-process flag; the risk is it leaking into a shipped game bundle |
| trace buffer → assertion surface | Trace entries are read by tests; must not carry hidden-info payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-128-01 | Tampering/Elevation | animation test-mode flag | mitigate | Flag defaults OFF; only `enableAnimationTestMode()` sets it; module never reads `import.meta.env` and is never toggled by prefers-reduced-motion — a shipped game cannot silently enter instant/recording mode |
| T-128-02 | Information disclosure | trace buffer contents | mitigate | `AnimationTrace` records element identity strings (data-bs-el-id/name/notation), container names, and geometry in `meta` only — recorder never stores card face values or hidden attributes; documented in the module header |
| T-128-SC | Tampering | package installs | accept | No npm/pip/cargo installs in this phase (RESEARCH: "installs no external packages") — supply-chain surface is empty |
