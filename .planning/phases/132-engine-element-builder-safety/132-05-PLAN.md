<objective>
Implement ENG-08 (F28): remove the silent-registration hazard where an action chain ending in `.build()` (never `.execute()`) registers a no-op action. `.build()` produces a definition flagged handler-less; `registerAction()` throws an actionable error on handler-less definitions at registration time.

Purpose: The action-builder constructor seeds a default `execute: () => {}`, and `registerAction()` currently performs zero validation, so a handler-less action registers silently and does nothing. Per CONTEXT, `.build()` stays available for inspection but must be rejected loudly at registration — a NEW registration-time validation, distinct from the existing `startFlow()`-time validators (RESEARCH Pitfall 4).
Output: A handler-less marker on `ActionDefinition`, a `.build()`/constructor flag, a `registerAction()` throw, and a red-first regression test.
</objective>
