    Create `src/cli/slash-command/bs/build/redteam.md`.

    State the fresh-context, no-framing constraint concretely (143-RESEARCH.md Pitfall 1 +
    fresh-context caveat): each of the 3 agents is a SEPARATE Task-tool dispatch whose only prompt
    content is the raw slice path(s) + the numbered claims list text — never the orchestrator's
    running conversation, the investigate subagent's prompt, or any peer agent's verdict. Prohibit
    confidence adjectives ("the investigator believes", "likely correct") in the dispatch prompt.

    Three dispatch templates (illustrative prose blocks in transcription.md's register):
      - Refuter ×2 (identical prompt, independent dispatch): read the slice(s) + RULINGS.md (rulings
        outrank the rulebook — cite state-machine.md "Rulings Outrank Rulebook"); for each claim
        decide whether the cited slice + RULINGS.md supports it as written; DEFAULT TO REFUTED when
        uncertain (do not give the benefit of the doubt). Return exactly using the pinned fields:
        a list of `{ claimNumber, verdict: 'stands' | 'refuted', objection }`.
      - Coverage adversary (separate prompt): review for COMPLETENESS not correctness — read
        `rulebook/INDEX.md`, search for rules that interact with the chunk's topic but are cited by
        no claim; also read RULINGS.md. Return exactly `{ missingInteractions: [{ ruleDescription, citation }] }`.

    Escalation logic — CITE state-machine.md "Redteam Escalation" and "Repair Loop Bound" (do not
    restate the max-1-round bound or refuted-twice rule): refuted-once → re-investigate with the
    specific objections attached, maximum ONE re-investigate round (hand off to
    `build/investigate.md`'s re-investigate behavior — append a superseding claim, never renumber);
    refuted-twice (both refuters agree, or a refuter + coverage adversary flag the same claim) → an
    ambiguity → escalate to the user.

    Vote-privacy (143-RESEARCH.md Pattern 5): per-agent verdicts are internal signal held by the
    orchestrator until all 3 return; the user NEVER sees a raw vote tally or an agent transcript —
    only a plain-language question with Option A / Option B when escalation triggers. Include the
    escalation-framing example (plain-language question + options, "or is this a house-rule
    choice?"). The answer is recorded as a `### Ruling N` entry in RULINGS.md (fill
    RULINGS.template.md's Decision / Citation / Rationale shape; never restructure the header).

    Footer: cite `build/investigate.md` (upstream claims producer + re-investigate owner) and
    `build/ask.md` (downstream consumer of the settled interpretation).
