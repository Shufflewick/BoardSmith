## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer → user filesystem (~/.claude or ./.claude) | The only bytes written; all dest paths are installer-constructed `join(targetDir, …)`, never derived from untrusted input |
| source tree → installed set | The copy filter decides what ships; a filter miss leaks BoardSmith test code into a user install |
| installer → global npm registry (npm link) | The npm link step mutates global state; the new skipLink option lets tests bypass it entirely |
