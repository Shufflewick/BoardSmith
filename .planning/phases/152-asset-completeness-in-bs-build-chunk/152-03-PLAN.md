<objective>
Add the ASSET-02 gate as a new first-class module `src/cli/lib/asset-scan.ts`, mirroring
`sandbox-scan.ts`'s single-source-of-truth shape. It is a file-system-level static scan (never an
HTTP probe — Vite's SPA fallback serves 200 for missing assets, Pitfall 2) that FAILS on any bare
`<img` tag found in generated/custom UI source outside `AssetImage.vue`'s own definition (the coarse,
pit-of-success heuristic locked in CONTEXT.md — any bare `<img>` is an automatic FAIL regardless of
`src`). Proven by a before/after fixture pair: an asset-referencing-but-asset-less UI FAILs; the
same UI wrapped in `AssetImage` PASSes — exactly the class that let DEF-A ship green.

Purpose: Give the pipeline a real, testable, build-blocking gate so an asset-less game fails the bar.
Output: `scanAssetReachability(cwd)` + `asset-scan.test.ts` with the fixture pair.
</objective>
