<objective>
Fix the two ENGINE-layer simultaneous-step defects and stand up the shared fixture the rest of
Phase 160 builds on:

- **D3 / SIM-01 (the load-bearing aliasing fix):** `getState()` (`engine.ts:619`) returns the private
  `FlowEngine.awaitingPlayers` array BY REFERENCE. Per-seat `completed` lives only on that transient
  array (`engine.ts:257`), is excluded from `FlowPosition`, and is stored un-cloned into every
  `ActionCheckpoint.flowState` (`snapshot.ts:236`). `resumeSimultaneousAction` then flips
  `playerState.completed = true` in place (`engine.ts:569/584`), retroactively overwriting every prior
  checkpoint's `completed:false`. Restore already deep-copies (`engine.ts:759-761`) but the loss is at
  CAPTURE, so restore cannot recover it. Fix at the single source: deep-copy `awaitingPlayers` in
  `getState()`.
- **D21 / SIM-03:** `executeSimultaneousActionStep`'s empty-guard (`engine.ts:1534`) short-circuits
  BEFORE the `allDone` check (`:1540`). An awaiting frame that reaches an empty/all-completed awaiting
  set with `allDone` unsatisfied leaves the frame awaiting with no eligible seat → the next `resume`
  throws "No player specified and no awaiting players found" (`engine.ts:519-520`). Fix at the source:
  consult `allDone` on the empty-awaiting branch and complete cleanly.

Purpose: D3 is foundational — Plan 02's per-seat undo can only restore a correct `completed` map once
the checkpoint stops aliasing the live array. D21 removes a hard crash on the same subsystem.

Output: the one-line-locus getState copy, the reordered empty/allDone guard, a net-new reusable
`simultaneous-fixture.ts`, and two RED→GREEN regression tests with adversarial verification.
</objective>
