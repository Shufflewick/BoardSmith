**Domain note — the deliverable is Markdown skill text, not TypeScript.** `bs/ingest/*.md`
are instructions installed verbatim to `~/.claude/skills/bs-shared/ingest/` and consumed by an
LLM agent. Their only runtime consumer in this repo is the grep-style assertion suite in
`ingest.test.ts`. Tests assert on the skill *text*, never on LLM output.

**Requirement-ID collision hazard (READ THIS).** `ingest.test.ts` already has `describe`
blocks literally named `INGEST-01` … `INGEST-07` — those are the **v4.6** requirement IDs
(v4.6 INGEST-01 = transcription per-section confirmation). This phase's INGEST-01..04 are
**v4.9** IDs with completely different meanings. Every new describe block in this phase MUST
be named with a `v4.9 ` prefix (e.g. `v4.9 INGEST-02 — Derived/Visual split`) so `-t` selectors
are unambiguous and no reader confuses the two generations. Do NOT rename or edit the existing
v4.6 describe blocks.

**No installer change is needed.** `install-claude-command.ts` recursively copies the whole
`ingest/` directory via `SHARED_DIRS`; edits to existing files are picked up automatically.
