<objective>
PROC-01: prove the Plan 01 + Plan 02 skill-text edits against a **real ingest run**, not against
skill-text review alone — then capture that run's `rulebook/INDEX.md` verbatim so Plan 04 can
derive its golden fixture from real output rather than hand-authoring it.

Purpose: A skill-text contract test proves only that the *instructions* say the right thing; it
cannot prove an agent following them produces the artifact. Closing that gap is the discipline this
phase exists to establish, and it must close on this phase's own work first.

**All four INGEST edits get real-run proof here, not three of them.** INGEST-01/03/04 are visible in
`rulebook/INDEX.md`; INGEST-02 (the `Derived`/`Visual` split) is visible only in the produced
`rulebook/NN-topic.md` slices, so the checklist below inspects those too. A desk-walkthrough of
pre-existing lines in another game is skill-text review, which ROADMAP success criterion 4
explicitly rules out as sufficient.

**The gaps check is a transport test, not a formatting test.** `openGaps[]` is a brand-new return
field with a brand-new consumer; RESEARCH.md Pitfall 2 names its silent-failure mode precisely — the
orchestrator dutifully writes an always-emitted section while the markers never actually arrive,
producing a well-formed `_None._` that looks like a pass. Because `seven` is independently known to
carry marked gaps, this run is the one place that failure is detectable, and item (e) below is
written so it cannot be passed by it.

Output: a captured real `INDEX.md` and a written PROC-01 evidence record.

**Ordering note (deliberate, per 170-RESEARCH.md Pitfall 3):** this plan is sequenced BEFORE the
golden-fixture plan. `seven`'s current on-disk `INDEX.md` predates this contract — it has no header
block at all and uses the pre-standardization heading
`## Open Rules Gaps (named-but-undefined in the source)`. Hand-adapting it would pin a shape the
skill text does not actually produce. The fixture must be derived from this run's output. That is
why Plan 04 sits in its own wave behind this human gate; the sequencing cost is accepted knowingly.
</objective>
