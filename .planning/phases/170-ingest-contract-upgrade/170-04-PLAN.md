**CI determinism is a locked decision.** The fixture is a static checked-in file. CI never runs an
ingest session, never invokes an LLM, and never diffs live run output. The live run was Plan 03's
manual proof and is recorded in its SUMMARY.

**Fixture location convention:** this repo keeps test fixtures in a `__fixtures__/` sibling
directory (`src/cli/lib/__fixtures__`). Follow it: `src/cli/slash-command/bs/__fixtures__/ingest-index/`.

**Installer note:** the fixture must live under `__fixtures__/`, NOT under `bs/ingest/` —
`install-claude-command.ts` recursively copies the whole `ingest/` directory into every designer's
skill tree, and a test fixture shipped as skill text would be read by a real agent as instructions.
