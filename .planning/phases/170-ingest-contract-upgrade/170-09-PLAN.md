<objective>
Capture the passing harness run's artifacts as durable in-repo evidence, then run the PROC-02
discipline across all six of this phase's requirements and record a single unhedged verdict.

Purpose: PROC-02 is fix, then test, then adversarially verify the fix holds, then close. This phase
already closed all six requirements once on the strength of green contract tests and had to reopen
every one of them. The circularity check is what prevents a repeat: for each requirement, state
whether it is satisfied only by text the test itself asserts, and name the independent evidence. In
this phase, "independent evidence" has exactly one acceptable form — a produced artifact from a live
agent run.

**Disposition of the superseded `170-04-PLAN.md`, stated explicitly.** That plan's Task 1 and Task 2
are **superseded**: they planned to derive a golden `INDEX.md` fixture from the Plan 03 proof run's
real output, and that output is non-conforming, so it cannot be a golden fixture. Its replacement is
already built and better placed:
- The **contract** is now `templates/INDEX.template.md` itself, pinned by `templates.test.ts`
  (Plan 07 Task 3). The contract is a shipped artifact rather than a test-only fixture, so it cannot
  drift from what ingest actually copies.
- The **artifact-shape test** is now `scripts/ingest-harness/check.test.mjs` (Plan 05 Task 3), which
  asserts the checker's judgment against both a conforming tree and the real non-conforming output —
  strictly stronger than a single golden fixture, because it pins the failing case too.
- The **empty-gaps state** is covered by the checker's `_None._` branch and its self-test, not by a
  second constructed fixture file.
`170-04-PLAN.md` Task 3 is **salvaged**: it becomes this plan's Task 2, with its circularity-check
structure kept and its evidence sources repointed from the failed run to the passing one. Do not
execute `170-04-PLAN.md`; it stays on disk as history.
</objective>
