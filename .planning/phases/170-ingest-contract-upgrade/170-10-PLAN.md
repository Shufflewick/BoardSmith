checkpoint, gated on the automated harness passing first.

Purpose: the harness is a proxy, and a proxy's job is to make failures cheap, not to replace the
thing it proxies. It drives a headless session with a prompt that pre-answers the ingest questions;
a human session answers them naturally, at a different pace, with different phrasing. PROC-01 asks
for a real ingest run, and this is it. The harness's contribution is that this human session is now
expected to pass — three human sessions were spent finding what one harness run now finds in
minutes, and none should be spent that way again.

including the unconditional gaps-count reconciliation, which was correct then and is correct now. No
criterion is weakened, and the zero-`Visual` waiver in item (h) remains available only on the terms
it was originally written under — an explicit statement that the two PDF pages contain no diagram,
art, layout, or typography note sitting mid-rule, which `seven`'s own produced `00-visual-survey.md`
has contradicted in every run so far.

all eleven artifact checks plus gate item (g) passing, and `170-PROC-02.md` opens with a `CLOSED`
verdict for the five non-PROC-01 requirements. If either is false, this plan does not run — spending
a human session on a known-failing contract is exactly the cost this replan exists to eliminate.
