<objective>
Fix F-1 from `170-PROOF-RUN-2.md`: `--edition` currently writes free text verbatim, so a paraphrase
like `none stated in the rulebook — © 2020 Alright Games` displaces the machine-checkable
`EDITION_UNKNOWN` sentinel. Phase 171 records the edition into every chunk's provenance block and
groups chunks by it, so the sentinel must be machine-checkable before anything reads it.

Purpose: PROV-01 records "rulebook edition" and PROV-03 groups by it. Both reference games carry
non-canonical edition free text today — this is live data, not a hypothetical.
Output: `normalizeEdition()` + `EDITION_EMPTY_LEXICON` exported from `ingest-archive.ts`, applied at
both INDEX.md write sites, with an `Edition note:` line preserving the designer's original wording.
</objective>

Decision 5 (CONTEXT.md) is the binding instruction: "Normalise recognisably-empty edition strings to
`EDITION_UNKNOWN`, or refuse them and tell the caller to omit the flag." This plan takes the
normalise branch, because refusing would make both reference games' existing `INDEX.md` files
non-conforming with no migration phase in the milestone (REQUIREMENTS.md "Out of Scope": no
backfilling).

Decision 2 (CONTEXT.md): "Any human note goes in a separate adjacent field that nothing parses."
That is what the `Edition note:` line is — it is deliberately NOT added to `HEADER_LABELS`.

<interfaces>
Existing exports in `src/cli/commands/ingest-archive.ts` this plan extends:

  export const HEADER_LABELS = ['Edition:', 'Source:', 'Source hash:', 'Transcribed:'] as const;
  export const EDITION_UNKNOWN = 'not stated in the rulebook';
  export function renderIndex(params: {
    gameName: string; edition: string | undefined; archivedPath: string;
    sourceHash: string; transcribed: string;

The two sites that write the `Edition:` line today:
  - `renderIndex()` — `Edition: ${edition && edition.trim() ? edition.trim() : EDITION_UNKNOWN}`
  - `ingestArchiveCommand()` — `.replace(/^Edition:.*$/m, \`Edition: ${options.edition?.trim() || EDITION_UNKNOWN}\`)`

The real strings this must handle, read from live project data 2026-07-28:

  one-two-punch:  `none stated in the rulebook — © 2020 Alright Games (transcribed from \`rules.pdf\`, 2 pages)`
