<objective>
Build the two computations at the heart of PROV-02 and PROV-01: what scope a verification honestly
has, and which rulebook slices a chunk actually cites. Both are pure functions in a new
`chunk-provenance.ts`; no CLI registration and no file writing land in this plan.

Purpose: PROV-02's entire point is that a partial verification must not be able to present as a full
one. A session asked to declare its own scope is exactly how that fails silently (CONTEXT.md decision
1), so scope is a hash comparison this code performs and nothing else can override.
Output: `computeVerificationScope()`, `resolveCitedSlices()`, `SCOPE_REASONS`, and their tests.
</objective>
