<objective>
Write the `/bs-verify-game` skill: an entry point plus a `bs/verify/` sub-step tree that resolves
the source, allocates a staging run, fans out re-transcription to subagents, and records each
completed unit through the ledger CLI.

Purpose: this is the judgment half of the phase. Every mechanism it needs already exists as a
command (plans 173-01 and 173-02) or as a shared contract (plan 173-03); skill text's only job is
orchestration and gating. Decision 14: VERIFY-07 is enforced structurally by the subagent writing
its own output and returning a summary — this file must not try to enforce it by restatement alone.

Output: four files under `src/cli/slash-command/bs/`.

**Scope fence.** This skill classifies NOTHING (decision 16) — no comparison, no verdict, no
labels. It stages and records. It never writes, promotes, or deletes a live slice; there is no
`--apply` and no cutover (decision 8). Any prose that compares pass 1 to pass 2 belongs to Phase 174
and must be rejected here.
</objective>
