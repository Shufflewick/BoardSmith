# Expected: `cosmetic` — the schema-asymmetry trap

The only rule-bearing line on both sides is identical: "A player may attack once per turn." The
live side additionally carries a legacy `Derived (p.2) — diagram description:` presentation note
(pre-Phase-170 schema); the staged side carries a real `Visual (p.2):` presentation note (current
schema). The two presentation notes describe wildly different things (a labeled rules diagram vs.
plain decorative art) — but BOTH are excluded from the rule delta by decision 12b's dual-schema
filter, so this difference must never surface as a delta at all.

A classifier whose exclusion filter only recognized `Visual (p.N):` would read the live side's
`Derived — diagram description` line as rule-bearing content, find no matching line on the staged
side, and manufacture a `sharper` or `contradictory` verdict out of pure schema drift. The correct
verdict is `cosmetic`, because once both presentation notes are properly excluded, the two sides'
rule-bearing content is byte-identical.
