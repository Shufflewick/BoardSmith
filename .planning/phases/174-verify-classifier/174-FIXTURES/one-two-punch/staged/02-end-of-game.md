# End of Game (p.2)

p.2, End of Game:
Once a player has broken all 3 of their opponent's Guard cards, they have knocked them out and immediately win the game! If both players manage to knock each other out during the same action, it is a draw.

Derived (p.2): Win condition — breaking (removing) all three of the opponent's Guard cards ends the game immediately in favor of the breaker; the game does not finish the current action or round first.
Derived (p.2): Simultaneous mutual knockout within the same action slot is a draw, so the game admits a non-win terminal state.
Derived (p.2): Because only Punch breaks Guards, a win requires at least three connecting Punches over the course of the game.
