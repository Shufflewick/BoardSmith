# Definitions (p.1)

p.1, Definitions:
Hand: The cards each player holds. Each starts with 3 and ends the game with 10.
Set: 2+ cards with matching numbers. example: 5, 5, 5
Run: 3+ cards in numeric order. example: 5, 6, 7

Derived (p.1): A Set requires a minimum of 2 cards sharing the same number; card color is not
part of the Set condition.
Derived (p.1): A Run requires a minimum of 3 cards in consecutive numeric order; the example
(5, 6, 7) is mixed-color, so color is not part of the Run condition.

## Worked examples (exact contents)

Set example (p.1): three cards showing the number 5 — green 5, green 5, purple 5.
Run example (p.1): three cards in numeric order — red 1, blue 2, red 3.

Visual (p.1): Each definition example is illustrated with small rounded-corner card graphics: a
solid color face (red, green, blue, or purple) with a large white bold numeral centered, and a
ring of small white pips arranged around the numeral near the card edges. Cards are portrait,
roughly 2:3 (width:height).
Visual (p.1): Definition terms ("Hand:", "Set:", "Run:", "example:") are set in bold black inline
lead-ins rather than as separate headings.
