# End of Game (p.2)

p.2, End of Game:
Once a player has broken all 3 of their opponent's Guard cards, they have knocked them out and immediately win the game! If both players manage to knock each other out during the same action, it is a draw.

Derived (p.2): The win condition is exactly "opponent has zero Guard cards remaining" — Guards must be broken (removed from the game), not merely exhausted.

Derived (p.2): The win is immediate, so the game can end mid-round — it does not wait for the second action pair or for the Discard phase.

Derived (p.2): A draw is possible and is the stated outcome when both players are knocked out during the same action. This can only arise from a simultaneous resolution, which by the p.1 tie rule means both players played the same card type in that slot — in practice, mutual Punches that each break the other's last Guard.

Derived (p.2): Because the simultaneous-Punch rule on p.2 requires a corner player's self-exhaust to be fully applied before either Punch resolves, a corner player whose last ready Guard is spent on that cost can still win or draw on the Punch that follows.

Derived (p.2): There is no round limit, score track, or timer — the only terminal states are a knockout and the simultaneous double-knockout draw.
