<objective>
Close GAP 1 — the phase's own self-reported goal failure. `buildBlindDerivePayload`'s `Target line`
identifier carries no meaning inside a quote-only payload, so every multi-candidate slice in the
real corpus collapsed to re-deriving the same dominant fact, and 177-PROOF.md's measured 56%
`disagrees` rate is dominated by that artifact rather than by genuine mismatches.

Purpose: a "second opinion" about the wrong fact is not a second opinion. This plan makes the target
identifiable to the blind subagent WITHOUT leaking the withheld inference, and — equally important —
builds the instrument that can tell a targeting-collapse artifact apart from a genuine disagreement,
so the re-run in plan 177-12 measures something real.

Output: an opaque target handle (closing CR-07's leak vector at the same time), quote-local focus
narrowing so per-candidate payloads genuinely differ, a mechanical per-slice payload-distinctness
signal, and a first-class `factAlignment` measurement on every compare-derived record.

Design note, binding: 177-CONTEXT.md decision 6 freezes the verdict set at FOUR. `factAlignment` is
a separate measurement field, never a fifth verdict — do not extend `DERIVE_VERDICTS`.
</objective>

<interfaces>
The measured collapse this plan exists to fix (177-PROOF.md §3, verbatim evidence):

`seven`'s `01-definitions-and-components.md` has 5 candidate lines (8, 14, 19, 21, 33). Each was
dispatched with an IDENTICAL quote-line payload, differing only in
`Target line: rulebook/01-definitions-and-components.md:{8,14,19,21,33}`. All 5 returned
functionally the same "7 x 4 x 4 = 112 numbered cards, + 7 bonus, 119 total" deck arithmetic. Lines
19 and 21 are actually about deck composition (correctly `agrees`); lines 8, 14, 33 are about card
art and imagery, so the same collapsed derivation landed `disagrees` against them — not because the
original derivation was wrong, but because the blind stage never attempted to derive what those
lines assert. The same pattern repeats in `01-overview-setup-and-play.md` (36/38/42),
`02-solo-variant.md` (11/17), and `02-action-cards-and-resolution.md` (95).

The one genuine content disagreement in the whole run — `one-two-punch:52`, box-split 8 per player
vs. discard-adjusted round-1 hand of 6 — came from a slice with only 2 candidates, both about the
same subject. That is the shape the new metric must be able to distinguish from the 8 artifacts.

Current payload builder (`verify-derive-recheck.ts:349-362`):
```
[ BLIND_DERIVE_TOKEN,
  `Slice: ${slice.path}`,
  `Target line: ${entry.slicePath}:${entry.lineNumber}`,
  'Quoted rulebook content for this slice — your ONLY source material. ...',
  ...quoteLinesOnly(slice.text) ].join('\n')
```

CR-07's fix direction, verbatim: "never send resolvable slice coordinates to the blind dispatch.
Emit an opaque handle the orchestrator maps back to `(slicePath, lineNumber)` on return, and drop
the `Slice:` line entirely." Its three named directions for the targeting problem were: an opaque
handle mapped back by the orchestrator, quote-local narrowing, or a redacted-but-positioned marker.
This plan uses the first two together.

Quote-line shape in a real slice (from the transcription contract): a citation header line
`p.N, <label>:` followed by directly-quoted prose lines beneath it. That header structure is the
natural passage boundary for quote-local narrowing, and it is already RETAINED by `quoteLinesOnly`.
