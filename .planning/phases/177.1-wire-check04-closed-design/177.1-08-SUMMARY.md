## Deviations from Plan

**1. [Rule 3 — blocking-issue fix, disclosed rather than silently substituted] Dispatched via
`claude -p --model <pinned-id>` instead of the Task tool the plan's `<interfaces>` section names.**
This executor session's own tool surface (the one running this plan) exposes only `Read`, `Write`,
`Edit`, `Bash` — no Task/subagent-dispatch tool is available to invoke. Since the plan explicitly
forbids simulating or replaying (`<the_bar_is_already_set>`) and requires a real dispatch, `claude
-p` was used as the closest available faithful proxy: a genuinely independent, out-of-process,
real live call to the exact pinned model id, carrying the exact contract file plus the exact
CLI-built payload bytes, with each contract's own `BS-ENUMERATE-V1`/`BS-RECONCILE-V1` token-check
gate running for real on the live model (not bypassed or hand-satisfied). What is NOT reproduced
is the Task tool's own subagent sandboxing/context-isolation mechanics — a genuine, disclosed gap
between this proof and what a designer's live Claude Code session does when the orchestrator
dispatches through the Task tool. Recorded plainly in `PROOF.md`'s own "Deviation" section rather
than silently worked around.

**2. [Finding, not a divergence — recorded rather than tuned] Composed-fact/operand-id literals
diverged numerically from the 177-22 corpus's recorded ids (item 4 of the mechanical bar), for the
disclosed, expected reason.** `EnumeratedFact` ids are a deterministic hash of each fact's own
`statement`/`sourceSentence` text; this live run's enumerators wrote genuinely different wording
than the 177-22 corpus's enumerators did (different model dispatch, different day), so the ids
necessarily differ by construction — this is not a mechanical-pipeline bug. The actual guarantee
this criterion protects (correct arithmetic composition against the `Derived` line's own claim) was
independently confirmed correct in the same proof document (item 5), so this is reported as an
explained divergence, not silently smoothed over or treated as a criterion failure.

**3. [Live-only finding, reported honestly per instruction] The disclosed `validateGrounding`
tie-break hazard (177.1-03 Finding 2, re-observed unchanged in 177.1-06's replay) did NOT reproduce
on this live run.** L21's three magnitude-4/7 operand statements resolved to THREE distinct grounded
facts this run, not the collapsed-to-two-ids pattern the recorded-input replay showed — because this
run's live enumerators independently phrased each clause as a genuinely separate statement, where
the 177-22 corpus's recorded enumerators had phrased two of them closer to identical wording. Not a
contradiction of the disclosed hazard (it remains real and reachable, demonstrated by 177.1-06's
replay on different recorded wording) — it demonstrates the collapse is itself model-dependent, not
a fixed property of the source text. Reported plainly in `PROOF.md`, not tuned or re-run to try to
force the collapse to reappear.

**4. [Interpretation, documented rather than silently applied] The independence-grep acceptance
criterion was checked against the CLI-built `enumeratorPayload` bytes specifically, not the full
text sent to the `claude -p` process.** The full dispatch text (contract prose + payload) shows 7
regex matches per slice; all 7 fall inside `enumerate-facts.md`'s own instructional prose describing
the exclusion rule (its "you never see... any `Derived (p.N):` line" statement and worked example),
zero fall inside the appended payload section — confirmed by partitioning every match by character
offset against the payload's known start position. `verify-game.md`'s own Context-Economics
carve-out text supports this reading ("the enumerator prompt... that is its entire payload... is
the `slices[].enumeratorPayload` bytes"), and this is the same "documenting the forbidden pattern is
not a leak" shape 177.1-07's SUMMARY already established for its own absence probes. Both the
narrower payload-only check (0 matches, the criterion that matters) and the broader full-text
check (7 matches, all in contract prose, zero in payload) are reported in `PROOF.md` rather than
picking one silently.
