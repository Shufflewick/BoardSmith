control?

  the slice's own rulebook text, unchanged since baseline. A correct implementation cannot diverge

  same unchanged rulebook text; `enumerateDerivedLines` is unmodified since 177.1-04.

  inputs (the enumerator side needs no adaptation at all).

  being applied consistently — which this pre-registration commits to doing, and which Task 2's

  is a pure function of the composed facts, grounded facts, and claims, all deterministic given the
  same input.

  pre-registration commits to a membership bar instead, mechanically derived above, never
  hand-picked.
