<objective>
Build source-free mode's mechanical core: the ONE definition of the verify pipeline's steps, which
of them can run without a source rulebook, and — for those that cannot — the designer-facing defect
classes that consequently go unchecked. Plus decision 7's test, which fails the moment the pipeline
grows a step that this definition does not cover.

Purpose: SC-2 ("names exactly which defect classes went unchecked") is only durable if the list is
DERIVED and if its coverage of the real pipeline is asserted. A hand-authored list is true the day
it ships and silently false afterward.
Output: `verify-source-free.ts` + its test file. No CLI surface yet (plan 02), no skill text yet
(plan 04).
</objective>
