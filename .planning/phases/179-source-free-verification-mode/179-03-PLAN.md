<objective>
Give a verify pass a way to durably record what it verified against. Today `## Verified Against` is
written by exactly one function — `chunkCheckCommand` — and every call site is in the BUILD
pipeline; `verify-game.md` and every file under `verify/` dispatch it zero times. That is why SC-3
is unmet by construction: the mode can COMPUTE `code-conformance-only` correctly and still never
record it anywhere a later reader can find.

This plan builds the write. Plan 04 dispatches it from both Closes.

Purpose: PROV-02 ("a verification that could not re-read source records its scope as
code-conformance-only") is closed on the build path only. This makes the mechanism reachable from
the pipeline its own text describes.
Output: an extracted reusable writer, a new `verify-close-record` command, and tests that pin
idempotency, designer-content preservation, scoping, and exit-0.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verify pass -> a real project's CHUNK.md | This plan makes a previously read-only pipeline WRITE to designer-owned files |
| computed scope -> durable claim | A block recorded with the wrong scope outlives the session that wrote it |
| touched-set derivation -> write set | An over-broad set rewrites chunks the pass never evaluated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-179-15 | Tampering | designer-authored CHUNK.md content | mitigate | Every edit bounded to the existing machine-owned fences by the ONE extracted writer; fence absence throws and writes nothing; task 1 and task 3 both assert byte-identity outside the fences |
| T-179-16 | Tampering | repeated Close runs churning files | mitigate | Writer compares rendered body against the previous body and writes only on change; per-file SHA-256 equality asserted across two consecutive invocations |
| T-179-17 | Elevation of Privilege | a scope-declaring option on a WRITE command | mitigate | No `--assume-full`/`--source-free`/`--force-scope`; scope comes only from `computeVerificationScope(projectDir)`, whose one-parameter contract is unchanged; asserted by grep criterion |
| T-179-18 | Denial of Service (of the Close) | one malformed chunk aborting the whole write | mitigate | Per-chunk try/catch into `errors[]`, printed loudly to stderr, remaining chunks still recorded, exit code stays 0 |
| T-179-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no packages |
</threat_model>
