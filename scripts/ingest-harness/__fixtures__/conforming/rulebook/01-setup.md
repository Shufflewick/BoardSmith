# Setup (p.1)

Setup, p.1:
Each player takes one starting hand of five cards from the shared deck. Shuffle the deck and
deal five cards to each player in turn order, then place the remainder face-down as the draw
pile.

Visual (p.1): The setup diagram on page 1 shows four player positions arranged around a central
draw pile, with an arrow indicating clockwise deal order.

Derived (p.1): Because each player receives exactly five cards and the draw pile is whatever
remains, the draw pile size equals the total deck size minus five times the player count.

Named-but-undefined (p.1): the "starting bonus" mentioned in the setup callout box (referenced by
name but its effect is never described anywhere on page 1).

Named-but-undefined (p.1): "turn order" is used before it is defined — the rulebook assumes the
reader already knows how turn order is determined, but no definition appears on page 1 or 2.

Derived (p.1): Since dealing proceeds strictly in turn order and the draw pile is placed only
after all hands are dealt, no player can see the draw pile's top card before their own hand is
complete.
